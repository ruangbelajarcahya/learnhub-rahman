LearnHub PWA — revisi ikon biru + tulisan LearnHub

Isi folder ini untuk diunggah ke root repository GitHub:
- index.html
- manifest.webmanifest
- sw.js
- icons/icon-192.png dan icons/icon-512.png

Cara pakai:
1. Ekstrak ZIP ini.
2. Upload ISI folder hasil ekstrak (bukan file ZIP) ke root repository GitHub.
3. Pertahankan folder icons beserta kedua file PNG di dalamnya.
4. Aktifkan GitHub Pages dari Settings > Pages, pilih branch utama dan folder /(root).
5. Buka alamat HTTPS GitHub Pages di Chrome Android, lalu pilih Install app / Tambahkan ke layar utama.

Catatan: fitur yang membutuhkan internet tetap membutuhkan koneksi. Data browser lokal tidak otomatis berpindah ke alamat GitHub Pages.
